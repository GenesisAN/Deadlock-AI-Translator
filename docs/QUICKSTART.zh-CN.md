# Deadlock AI Translator 快速上手

## Windows x86-64 安装

1. **解压 ZIP。** 如果正在使用旧版翻译桥，先退出旧桥和 Deadlock。
2. **启动翻译桥。** 双击解压目录里的 `deadlock-translator.exe`，游玩时保持终端窗口打开。首次出现 Windows 证书信任提示时，核对名称 **Deadlock Translator Go Local Root** 后确认，再完全退出并重启 Steam（包括系统托盘里的 Steam）。
3. **配置翻译服务。** 在浏览器打开 [本地设置页](http://127.0.0.1:8791/ui)，选择 DeepSeek 或其他服务商，填写所需的 API Key 并保存。如果之前已配置 Go 版，启动时会读取原有设置。
4. **安装游戏 Mod。** 用 Mod Manager 安装或替换解压目录里的 `pak23_dir.vpk`。手动安装时，在 Steam 的 Deadlock 菜单中选择「管理 → 浏览本地文件」，打开 `game\citadel\addons` 并复制 VPK。升级时替换旧的翻译 Mod，确保只加载一份。然后启动游戏。

## 游戏内用法

| 聊天框输入 | 效果 |
| --- | --- |
| `我去守家` | 按当前设置处理这条消息。 |
| `/t` | 开关发送前翻译，不影响接收翻译。 |
| `/r 我去守家` | 仅这条消息直发「我去守家」。`/raw` 也可以使用。 |

Go 桥接终端里的 `[聊天][收]` 和 `[聊天][发]` 分别显示收到和发出的消息，包括原文、译文以及直发等状态。可在网页设置里切换「在终端显示聊天原文和译文」。发送前翻译最终失败的消息不会进入 `[聊天][发]`，因为它并未发出。

开启发送前翻译后，如果翻译失败，会额外重试 3 次。全部失败时消息不会发出，原文会留在输入框，游戏里仅自己能看到故障提醒。确需发送原文时，可手动使用 `/r` 直发。

AI 翻译默认优先使用玩家熟悉的游戏术语和常见网络短语，保持聊天原本的语气和简短表达。设置页的「提示词」可继续补充个人偏好；非 AI 翻译服务主要使用内置词库中的固定译法。

游戏内 AI 翻译还会参考本次游戏会话中最近 10 条收发消息的原文（总计最多 1000 字符），用于判断简称、代词和连续对话。此前消息只作背景，AI 只翻译当前句；传统翻译服务不会收到这些原文。上下文仅保存在游戏侧内存，重启游戏或聊天界面重建后清空。关闭终端聊天日志不影响这项翻译上下文。

为了之后分析译法，Go 桥默认把每次成功的游戏内 AI 调用按日期写入本机配置目录的 `translation-samples/YYYY-MM-DD.jsonl`。每条包含当前原文、收发方向、实际发给模型的系统提示与当前句、服务商和模型、最终译文；提示中可能含最近 10 条聊天原文。记录器不会从服务商配置读取 API Key，也不会自动上传。缓存命中、词库直接命中、传统翻译和设置页试译不产生样本。该目录会持续积累，可自行备份或删除；启动时加 `--collect-samples=false` 可停止记录。此记录与「在终端显示聊天原文和译文」开关无关。

装备和角色的英文缩写、中文外号都放在对应词条下。无论收到英文聊天还是把中文发出去，AI 匹配到别名后都会看到英文正式名称与中文译名，再结合原句翻译。例如 BRS 对应 Bullet Resist Shredder／粉碎护甲，蓝牛对应 Abrams／亚伯兰；BKB 仍可按玩家习惯保留简称。

如果玩家使用了词库中没有的简称，AI 请求会附上按文本相似度排序的相关词条，让模型结合上下文选择。设置页的「试译」可展开查看实际候选；候选不会被当作确定译法强制替换。

如果 `/r` 被当成普通聊天发出，请确认游戏加载的是这个发布包里的 VPK。如果设置页能打开但游戏桥一直显示离线，请确认桥接终端仍开着，并在首次信任证书后重启 Steam。

## 更新

Go 桥启动时会在终端显示版本和程序的 SHA-256。本地设置页打开时会自动检查更新，也可以点击「检查更新」重试。发现新版后点击「安装更新」，完成后关闭并重新启动 Go 桥。若发布说明提到游戏 Mod 更新，从 GitHub Releases 下载对应平台的安装包，使用其中的 `pak23_dir.vpk` 替换游戏里的旧版。

在本地设置页打开「词库」，游戏词库可分别查看装备、角色、地图、单位、事件和行动；聊天词库包含常见游戏网络缩写。还可查看外置词库和自定义词条。输入关键词可搜索原文、译文和别名，修改译文后点击「保存词库」立即生效；展开「编辑完整内容」可增删词条或修改别名。项目随附的词库仍跟随程序发布，本机修改单独保存。新增自定义词条保存在独立文件，旧设置中的自定义词条会在启动时迁入。

## Linux x86-64 / Steam Deck

在解压目录运行 `./deadlock-translator --init-tls`，让 Steam 信任生成的根证书，再运行 `./deadlock-translator`。打开本地设置页，并用同一目录的 `pak23_dir.vpk` 安装游戏 Mod。Proton 下的游戏接入待实测。
